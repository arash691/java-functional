# ShopFlow: the one-page brief

ShopFlow is the project you build step by step during the course. For now you only need the big picture. Detailed requirements, vocabulary and design come later, after you have learned modeling.

## What it is
An online shop. Customers browse products, put them in a cart, place an order and pay. The shop keeps track of stock and order status.

## Who uses it
- **Customer**: browses, buys, tracks orders.
- **Admin**: manages the catalog and prices.
- **Warehouse operator**: updates stock, ships orders.

## What it will become
1. A command-line tool in plain Java (Phase 1).
2. A Spring Boot web service with a database and a React page (Phase 2).
3. A designed, tested, secure, deployed system with several services (later phases).

## What it is not (for now)
Real payments, returns, marketplace sellers, several warehouses.

## What you do not need to know yet
Database design, class design and architecture are *taught* in the modeling block (weeks M1–M8). Until then you only follow tickets from `shopflow-backlog.md`. If a word in a ticket is unfamiliar, write it down in `notes/questions.md` and keep going; the lessons will answer most of those questions.
