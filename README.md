# Java Backend Roadmap

A self-study programme that takes a strong frontend (JS/TS) developer to a senior Java backend engineer in about 60 weeks at roughly 10 hours a week. It is built around one evolving project, **ShopFlow**, and a practice repo where bugs and features are driven by tests.

## Start here
| Path | What it is |
|---|---|
| `LEARNER-GUIDE.md` | One-page guide for learners: how to start, what to do and not do, when stuck |
| `HANDOFF.md` | Current status, decisions, known issues and next steps (read first in a new session) |
| `java-backend-roadmap.md` | The overview: phases, timeline, gates, senior checklist, resources |
| `lessons/README.md` | How to study: session formats, learning modes, self-study playbook |
| `lessons/interview/` | Deep interview questions with teaching answers (Phase 0–1 so far) |
| `lessons/appendix/` | Optional reading: how the web works (DNS/TCP/TLS/HTTP), ports, Docker check |
| `lessons/pilot/week-01.md` … `week-12.md` | Project-first lessons for weeks 1–12 (the new format) |
| `lessons/modeling/m1…m8` | Modeling block between weeks 9 and 10: classes, OOD, domain concepts, 10 practical domains, data modeling |
| `modeling-lab/` | The 10 practical business briefs and the self-scoring rubric |
| `shopflow-brief.md` | One-page ShopFlow overview (read in Week 2) |
| `lessons/phase-*.md` | Step-by-step lessons for weeks 13–60 (older reading-first format; to be converted) |
| `shopflow-lab/` | Practice repo: exercises, incident tests, hints, solutions (`shopflow-lab/README.md`) |
| `shopflow-backlog.md` | The ShopFlow tickets that drive the build sessions |
| `reality-lab/` | Catalog of ~110 production-style problems and the ledger template |

## First steps
1. Read `lessons/README.md`, then `lessons/pilot/week-01.md`.
2. Run `shopflow-lab/scripts/run-week.sh w00` and make the first red test green.
