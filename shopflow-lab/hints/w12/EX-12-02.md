# EX-12-02 hints: a schema change

<details><summary>Level 1</summary>

A new column needs two changes that must agree: the database schema and the entity.
</details>

<details><summary>Level 2</summary>

Never edit `V1__create_product.sql`: Flyway has already applied it and stores a checksum. A change is a new file with a higher version number.
</details>

<details><summary>Level 3</summary>

File name pattern: `V<version>__<description>.sql` (two underscores) in `db/migration`. Version 2 is free (version 3 already exists for orders; Flyway orders by version).
</details>

<details><summary>Level 4</summary>

The column is nullable and at most 500 characters. On the entity add a field with `@Column(length = 500)` and a getter, plus a constructor that takes the description.
</details>

<details><summary>Level 5</summary>

`alter table product add column description varchar(500);` and in `ProductCatalog.create` build `new ProductEntity(sku, name, description, price)`, save it, and map the entity to a `ProductView`.
</details>
