# SF-08 hints: persistent cart

<details><summary>Level 1</summary>

Work bottom-up: table, entity, repository, service. Run `Sf08CartTest.emptyCart` first; it needs only the plumbing.
</details>

<details><summary>Level 2</summary>

Tables: `cart(id, customer_id unique)` and `cart_item(id, cart_id -> cart, product_id -> product, quantity > 0, unique(cart_id, product_id))`. Use `V4__create_cart.sql`.
</details>

<details><summary>Level 3</summary>

Look at `OrderEntity` / `OrderItemEntity`: your `CartEntity` / `CartItemEntity` have the same shape (one-to-many with `mappedBy`, cascade, `orphanRemoval`, lazy many-to-one).
</details>

<details><summary>Level 4</summary>

`LazyInitializationException` while building the `CartView`? The mapping touches lazy fields, so the service method must run in a transaction: `@Transactional` (readOnly for reads). Merge duplicate SKUs by looking for an existing item of the same product first.
</details>

<details><summary>Level 5</summary>

`addItem`: validate quantity, find the product by SKU (or throw `UnknownProductException`), find or create the cart, then either increase the quantity of the existing item or add a new `CartItemEntity`. `clear`: remove all items of the customer's cart (`orphanRemoval` deletes the rows).
</details>
