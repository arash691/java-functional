# EX-03-02: Sku.isValid (hardest exercise of the week)

Open **one level at a time**, and only after you have tried for about 10 minutes at the previous level.
Write down what you tried before opening the next level.

<details><summary>Level 1: the symptom, restated</summary>

Your `isValid` returns true for some strings that should be rejected, or crashes with `StringIndexOutOfBoundsException`.

</details>

<details><summary>Level 2: where to look</summary>

Check the *length first*, before you call `charAt`. Check `null` before checking the length.

</details>

<details><summary>Level 3: which tool to use</summary>

Write the cases on paper: for each index 0..7, what character class is allowed? Then write one small loop per class. Use the failing parameterized test name to see which input broke.

</details>

<details><summary>Level 4: the concept to search for</summary>

Search for: *Java char comparison*, *String.charAt*, *Character.isDigit vs '0'..'9'* (note that `Character.isDigit` accepts non-ASCII digits and `Character.isUpperCase` accepts non-ASCII letters, which this exercise does not allow).

</details>

<details><summary>Level 5: the shape of the fix (try to write it yourself first)</summary>

Return false early. Pseudocode: null or length != 8 -> false; indexes 0-2 must be 'A'..'Z'; index 3 must be '-'; indexes 4-7 must be '0'..'9'; otherwise true. `prefix` and `number` call a shared `requireValid` and then use `substring` and `Integer.parseInt`.

</details>
