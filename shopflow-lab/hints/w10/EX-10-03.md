# EX-10-03 hints: profiles

<details><summary>Level 1</summary>

The test fails with "expected a single bean". Right now neither shipping class is a bean at all.
</details>

<details><summary>Level 2</summary>

A class becomes a bean when it carries a stereotype annotation (`@Component`, `@Service`...) and is found by component scanning. Which annotation limits a bean to some profiles?
</details>

<details><summary>Level 3</summary>

The default case has NO profile active. Express must be active only for profile `express`. The other one must be active whenever `express` is NOT. Look at the profile expression syntax: `!name`.
</details>

<details><summary>Level 4</summary>

Search: "Spring @Profile annotation negation". Constructor injection of `ShopProperties` into `StandardShipping` gives it the free-shipping threshold.
</details>

<details><summary>Level 5</summary>

`@Component @Profile("!express") class StandardShipping` with a constructor `StandardShipping(ShopProperties shop)` and `costFor` returning 0.00 when the subtotal is at least the threshold; `@Component @Profile("express") class ExpressShipping`.
</details>
