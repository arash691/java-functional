# EX-09-03: MDC with guaranteed cleanup: hint ladder

Open ONE level at a time, and only after you have tried for 10 minutes.

<details><summary>Level 1: symptom only</summary>

The three tests ask for: the id is visible inside the action; it is gone afterwards; it is gone even if the action throws.
</details>

<details><summary>Level 2: where to look</summary>

SLF4J has a class called `MDC` with `put`, `get`, `remove` and `clear`. MDC values live in thread-local storage.
</details>

<details><summary>Level 3: the tool</summary>

Which Java statement guarantees that a piece of code runs both after normal completion and after an exception?
</details>

<details><summary>Level 4: the concept to search</summary>

Search: "slf4j MDC put remove finally" and "why clear MDC in thread pools".
</details>

<details><summary>Level 5: fix outline</summary>

`MDC.put("requestId", requestId); try { action.run(); } finally { MDC.remove("requestId"); }`
</details>
